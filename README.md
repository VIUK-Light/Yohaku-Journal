# Yohaku Journal

> 書くことに、余白を。
>
> 日々の出来事や気持ちを自分の言葉で記録し、静かに振り返るためのオープンソース・ジャーナルアプリです。

Yohaku Journalは、SwiftUIで開発している日記・振り返りアプリです。
記録を続けること自体を目的にせず、必要なときに書き、あとから自分の状態を見直せる体験を目指しています。

医療的な診断や重症度の判定を行うアプリではありません。日記、観察、非診断的なセルフチェック、根拠を明示した記事、相談先への導線を一つのアプリにまとめています。

## 主な機能

### 日記とタイムライン

- 日々の出来事や気持ちを記録
- 保存した記録を時系列で振り返り
- キーワードによる検索
- 添付ファイルを含む記録データの管理

### 観察と振り返り

- 記録した内容を期間別に確認
- 数値表とアクセシブルな要約表示
- 独自の質問による非診断的なセルフチェック
- 保存済みの振り返り結果をあとから確認

セルフチェックは、病名や重症度を決めるためのものではありません。標準尺度は、根拠・利用条件・安全導線の確認が完了するまで停止しています。

### 心の健康に関する記事

- カテゴリやキーワードによる検索
- 対象読者、出典、確認日、安全上の注意を明示
- 記事から共通の相談先カタログへ移動

### プライバシーとデータ保護

- Face IDなど、OSの端末認証を利用したアプリロック
- バックグラウンド移行時の自動保護
- パスワード付き暗号化バックアップの作成と復元
- バックアップ内容の検証、改ざん検出、競合処理
- アプリ内からの全データ削除

## 設計方針

Yohaku Journalでは、利用時間や継続日数を最大化することより、利用者が自分の意思で記録を管理できることを重視しています。

- 医療的な診断や、点数による重症度の断定をしない
- 他人の感情や関係性を決めつけない
- 広告、課金誘導、ランキング、連続記録の強制を設けない
- 危機対応と通常の振り返りを同一に扱わない
- 保存データと安全設定を利用者自身が管理できるようにする
- 支援が必要な場面では、人間の相談先へつながる選択肢を示す

## ビルド方法

```bash
git clone https://github.com/VIUK-Light/Yohaku-Journal.git
cd Yohaku-Journal
```

1. リポジトリ内の`.xcodeproj`をXcodeで開きます。
2. Yohaku JournalのSchemeを選択します。
3. 実行先のSimulatorまたは端末を選択します。
4. XcodeのRunボタン、または`Command + R`で起動します。

## 開発状況

現在は公開前の品質検証と改善を進めています。
主要機能は実装されていますが、実機でのプラットフォーム検証やバックアップ・復元の最終確認が残っている場合があります。重要な記録について、本アプリのバックアップだけを唯一の保存手段として扱わないでください。

## 安全上の注意

Yohaku Journalは医療機器、診断ツール、専門家による支援の代替ではありません。表示されるセルフチェックや記事は、自分の状態を振り返るための補助情報です。

差し迫った危険がある場合は、アプリ内の記録やセルフチェックだけで判断せず、地域の緊急窓口、医療機関、信頼できる人へ連絡してください。
